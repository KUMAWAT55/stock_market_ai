# TradeIQ 60-Day Beginner Learning Track

This track is for a complete beginner who wants to learn this project end-to-end.
You will learn Python, FastAPI, SQL, React, JavaScript/TypeScript, realtime systems, and ML concepts by using this codebase directly.

## How to Use This Track
1. Do exactly one day at a time.
2. Spend 90 to 120 minutes daily.
3. Keep a personal notebook for commands, diagrams, and mistakes.
4. Do the weekly review days seriously (Day 7, 14, 21, 28, 35, 42, 49, 56, 60).

## Folder Structure
- `day_01.md` to `day_60.md`: daily guided lessons.

## Weekly Milestones
- Week 1: Foundation and project orientation.
- Week 2: FastAPI and request lifecycle.
- Week 3: PostgreSQL and data layer.
- Week 4: React + TypeScript + routing + responsive UI.
- Week 5: Dashboard integration and analytics UX.
- Week 6: ML pipeline and feature understanding.
- Week 7: Realtime engine, risk flow, and auto backfill.
- Week 8: Testing, security, deployment, failure handling.
- Final 4 days: Capstone and next 90-day roadmap.

## Suggested Daily Routine
1. Read: 20 to 30 min.
2. Trace code flow: 20 to 30 min.
3. Hands-on task: 30 to 45 min.
4. Notes and recap: 10 to 15 min.

## Success Criteria After 60 Days
- You can explain full app flow from tick ingestion to dashboard rendering.
- You can debug common backend/frontend/data issues.
- You can implement small end-to-end features safely.
- You can plan next improvements with clear technical reasoning.
